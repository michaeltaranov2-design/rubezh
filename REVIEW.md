## Архитектура
ARCHITECTURE.md содержит схему и поток данных. C#: серверные разрешения, квоты, экономика, раунды, видимость, эффекты, протокол и UI. C++: пакетное движение, queries, история hitboxes, только с серверным подтверждением результата. Клиент предсказывает, но не подтверждает урон/выдачу/экономику. Нельзя передавать скрытые позиции, события урона, impacts, направление aim или метаданные, позволяющие восстановить закрытую цель. Spectator — не обход политики.

## Дублирование и мёртвый код
Дублирование лимитов текста/каталога выявлено; каталог принят источником истины, строгая проверка предотвращает drift. Исторические файлы намеренно не импортируются. Общий Geometry builder обслуживает варианты оружия, atlas/material создаются одной функцией. Python catalog_contract — тестовый эталон, не второй production runtime. Мёртвые ветки игрового C# исследовать нельзя: кода нет.

## Память, аллокации, потоки и ошибки
- Исходный пакет: runtime-процессов нет, утечки не измерялись. Отсутствие найденных утечек не означает безопасность.
- Генератор: выделяет массивы вершин/UV/пикселей offline; на тик игры эти аллокации не попадают. 128×128 atlas, ограниченная геометрия; Actions/meshes/materials/images очищаются между экспортами. Реальный RSS Blender не измерен.
- Python GLB validator читает весь файл и создаёт списки: предназначен только для небольших собственных экспортов, НЕ для сетевой загрузки непроверенных пользовательских карт.
- Blender bpy вызывается последовательно в главном потоке. Генерация/экспорт не распараллелены. Требования к сетевому потоку и native buffers описаны, не проверены runtime-тестом.
- Ошибки бюджета, материалов, sockets, клипов и экспорта прекращают пакет; manifest получает failed. Есть --python-exit-code 1 в инструкции. Повтор в непустой каталог запрещён. Частичные файлы не выдаются за принятый комплект.
