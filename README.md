## Быстрый запуск
Установите обычный Python 3.10+ и Blender. Распакуйте этот архив в отдельный каталог; он включает предыдущие исходники инструментария, не требуется накладывать обновление вслепую.

    python tools/run_weapons.py --out ./generated/session-01 --allow-newer --full

Blender ищется в PATH и типовых каталогах Windows/macOS. При нескольких найденных установках укажите точную:

    python tools/run_weapons.py --blender "C:/Program Files/Blender Foundation/Blender 5.0/blender.exe" --out ./generated/session-01 --allow-newer --full

Путь выше — пример, НЕ утверждение о вашей установленной версии. Замените его реальным. Без --full запускается только пробный пистолет с тремя LOD. Без --allow-newer разрешена лишь ранее выбранная ветка 4.5.x; флаг разрешает экспериментальную проверку более новых версий, а не гарантирует поддержку. Старые версии отвергаются.

## Что делает запускатель
1. Отказывается от перезаписи существующего каталога результата.
2. Выполняет тесты локальным Python.
3. Запускает отдельный Blender с --background --factory-startup, проверяет параметры glTF/NLA и привязку Action Slot.
4. Создаёт пробный pistol_klyn и проверяет три GLB и manifest.
5. Только после успешного пилота создаёт все 13 моделей (если передан --full), независимо проверяет 39 GLB.
6. Сохраняет session-report.json и отдельные журналы шагов; при ошибке останавливается.

Настройки Blender не сохраняются и не переписываются. Рабочие .blend пользователя не открываются. Все выходные файлы помещаются в новый каталог. Нет скачивания Blender, shell-команд или автоматического git commit.
